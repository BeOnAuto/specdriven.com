# Archetype

![Archetype](/images/pages/dialects/archetype.png)

> Status: in development.

The Auto team is working on **Archetype**, a spec dialect for describing complex software architectures using graphs of nodes and edges.

Where Narrative-Driven Development describes systems through time, Archetype describes them through structure: the components that make up a system, the relationships between them, and the constraints those relationships must satisfy. It's intended for systems where the architecture itself is the hard part (distributed systems, integration-heavy platforms, multi-service workflows), and where talking about behavior alone isn't enough to specify what you're building.
